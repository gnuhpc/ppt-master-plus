# Humanize PPT Bridge Workflow (`humanize-ppt-bridge.md`)

> **Purpose**: Enables `ppt-master-plus` to natively consume briefs, AST outlines, speaker intents, and per-page media decisions generated by `humanize-ppt` (LearnPrompt/humanize-ppt).

---

## Direct Brief Handoff Protocol

When `humanize-ppt` runs with `--renderer ppt-master`, it generates:
1. `ppt-master-source.md` — The input source text mapped from `ast_outline.md` and `slide_plan.json`.
2. `speaker_intent.md` — The per-page speaker action that maps to `notes/total.md` and `notes/<page>.md`.
3. `ppt-master-production-prompt.md` — The execution instruction.

## Execution Steps in `ppt-master-plus`

### Step 1: Project Initialization
Create project with `humanize-ppt` source:
```bash
python3 ${SKILL_DIR}/scripts/project_manager.py init <project_path> \
  --source <humanize_run_dir>/ppt-master-source.md \
  --format ppt169
```

### Step 2: Speaker Notes Injection
Copy `speaker_intent.md` into `<project_path>/notes/total.md`:
```bash
cp <humanize_run_dir>/speaker_intent.md <project_path>/notes/total.md
```

### Step 3: Strategist & Native Generation
Run the standard Strategist (Step 4) and Executor (Step 6) pipeline. `ppt-master-plus` will preserve the slide count, page order, and judge-title contract specified in `slide_plan.json`.

### Step 4: Presentation Checkup & Export
Run `critic_audit.py` to perform the Presentation Checkup (演讲体检) and export native DrawingML PowerPoint:
```bash
python3 ${SKILL_DIR}/scripts/critic_audit.py <project_path>
python3 ${SKILL_DIR}/scripts/finalize_svg.py <project_path>
python3 ${SKILL_DIR}/scripts/svg_to_pptx.py <project_path>
```
