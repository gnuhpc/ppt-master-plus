# Swiss Grid Brand Identity Preset

## I. Identity Metadata
- **Brand Name**: Swiss Grid System
- **Aesthetic Family**: `swiss-minimal`
- **Design Philosophy**: Form follows function, high contrast, rigorous grid alignment, generous whitespace.

## II. Color Scheme
- **Primary Color**: `#1D3557` (Deep Navy)
- **Accent Color**: `#E63946` (Swiss Crimson Red)
- **Secondary Accent**: `#457B9D` (Steel Blue)
- **Background**: `#F1FAEE` (Off-White Porcelain)
- **Secondary Background / Surface**: `#FFFFFF` (Pure White)
- **Body Text**: `#1D3557` (Deep Navy)
- **Subtle Border / Grid**: `#A8DADC` (Soft Teal)

## III. Typography
- **Title Stack**: `"Microsoft YaHei", "PingFang SC", SimHei, sans-serif`
- **Body Stack**: `Arial, "Microsoft YaHei", sans-serif`
- **Code Stack**: `Consolas, "Courier New", monospace`
- **Font Size Hierarchy (px)**:

  - **Page Title**: `36px`
  - **Body Baseline**: `18px`
  - **Annotation / Caption**: `14px`

## IV. Icon Style

- **Stroke Weight**: `N/A` (Solid fill)
