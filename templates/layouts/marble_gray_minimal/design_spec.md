# Marble Gray Minimal — Design Specification

## I. Template Overview
- **Use Cases**: Year-end summaries, high-end real estate bids, luxury branding reviews.
- **Design Tone**: Sophisticated, premium, solid marble textures with polished gold frame lines.
- **Theme Mode**: Light mode (warm light gray marble background texture).

## II. Color Scheme
- **Polished Gold**: `#C1A36C` (Border lines, bullets, and accents)
- **Charcoal Slate**: `#262626` (Primary titles)
- **Soft Light Gray**: `#F2F2F2` (Layout dividers)

## III. Signature Design Elements
- **Marble Backdrop**: Subtle grey marble stone surface graphic defining the slide background.
- **Double Rounded Frame**: Massive centered rounded rectangle border highlighting titles.
- **Timeline agenda**: Downward pointing gold arrow line with dot bullets representing catalog nodes.
