# Peach Blossom Fresh — Design Specification

## I. Template Overview
- **Use Cases**: Creative work summaries, school project displays, spring briefings.
- **Design Tone**: Cute, fresh, artistic, pastel colors with realistic peach blossom sketch borders.
- **Theme Mode**: Light mode (pure white canvas background with faint textured overlay).

## II. Color Scheme
- **Peach Pink**: (Blossom graphics)
- **Charcoal**: `#404040` (Primary text)
- **Background**: `#FFFFFF` / Soft warm textured layout

## III. Signature Design Elements
- **Blossom Borders**: Layered peach blossom flowers outlining the top corners and bottom edges.
- **Cute Vertical Serif**: Styled vertical fonts for cover & divider pages.
