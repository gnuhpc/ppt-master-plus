# Ink Smoke Minimal — Design Specification

## I. Template Overview
- **Use Cases**: Chinese traditional cultural reviews, creative briefings, artistic portfolios, philosophy presentations.
- **Design Tone**: Atmospheric, calm, traditional, rich grey watercolor textures.
- **Theme Mode**: Light mode (soft off-white watercolor base canvas).

## II. Color Scheme
- **Ink Charcoal**: `#595959` / `#262626` (Primary calligraphy text and lines)
- **Mist Grey**: `#A6A6A6` (Secondary subtitle text and overlay textures)
- **Canvas White**: `#FFFFFF` (Background)

## III. Signature Design Elements
- **Ink Smoke Backdrops**: Gorgeous high-definition ink wash patterns framing headers and layouts.
- **Vertical Scripture**: Giant vertical Chinese characters on covers and dividers.
- **Line Marker**: Thin charcoal vertical divider bars dividing headers from content.
