# Minimal Clean 18 — Design Specification

## I. Template Overview
- **Use Cases**: Creative project portfolios, elegant work summaries, minimalist reports.
- **Design Tone**: Artistic, calm, professional, high contrast vertical text accents.
- **Theme Mode**: Light mode (soft gray / white background).

## II. Color Scheme
- **Slate Navy**: `#203864` (Primary headers and large vertical text)
- **Background**: `#E8E9EB` (Soft slate gray canvas background)
- **Muted Blue**: `#949AB2` (Lines and subtitles)

## III. Signature Design Elements
- **Vertical Accent Lines**: Long vertical slate blue lines structuring the cover and chapters.
- **Side Panel Photo**: Left side-aligned image on TOC page.
