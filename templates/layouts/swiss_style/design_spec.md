# Swiss Layout Specification

## I. Template Overview
- **Design Style**: Swiss Internationalism. Sharp, straight-angled, modular grid layout.
- **Rhythm**: Aggressive whitespace, massive typography size contrast (ExtraLight headings).
- **Theme**: High-contrast single accent color (Klein Blue) on white background.

## II. Layout Elements
- Flat solid grey cards (`#F5F5F5` or `#EAEAEA`) for grouping statistics.
- Hairline rules (`stroke-width="1"`) for structure.
- All text blocks aligned flush to the left margin.
- Zero border radius (`rx="0"`) on all elements.
